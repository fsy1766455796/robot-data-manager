# Robot Data Manager

地図・rosbag をローカルのブラウザーで確認する管理ソフトです。ROS のインストールは不要です。日本語 UI、macOS / Linux 向け。実データをクラウドに送信しません。

## 起動する

必要なもの：Python 3.9 以降。初回のみライブラリの取得にインターネット接続が必要です。

```sh
git clone https://github.com/fsy1766455796/robot-data-manager.git
cd robot-data-manager
bash start.sh
```

Mac では `start.command` をダブルクリックしても起動できます。Ubuntu で仮想環境を作れない場合は `python3-venv` パッケージをインストールしてください。

起動スクリプトが必要なライブラリを専用環境にインストールし、ブラウザーで **http://127.0.0.1:8765** を開きます。停止はターミナルの Ctrl+C。Windows の自動検出・起動は未検証です。

## データの自動検出

固定の SSD 名・ユーザー名・研究室のパスを設定する必要はありません。

- Mac：`/Volumes` にマウントされている外部ドライブ。
- Linux：`/media`、`/run/media`、`/mnt` と、その直下のユーザーディレクトリーにマウントされたドライブ。
- ホーム内の `ros2_ws/rosbag`、`ros2_ws/bags`、`ros2_ws/maps`、`rosbag`、`rosbag2`、`maps`。

候補内に rosbag / PGM / 三次元地図のファイルが見つかると、データソースに追加します。探索は各候補の深さ 5、最大 1,500 ディレクトリーに制限します。全ディスクを無制限に検索するものではありません。シンボリックリンク、回収箱、隠しフォルダー、システム用フォルダーは除外します。

SSD を接続・取り外した後は「再スキャン」で候補を再検出します。見つからない場所や PNG のみの地図フォルダーは、手動指定してください：

```sh
bash start.sh --root "/path/to/data"
```

`--root` は複数回指定可能です。相互に重複する指定は拒否します。自動検出が不要な場合は `--no-auto`、別のポートは `--port 8766` を付けます。

## 機能

- 地図をフォルダー単位で一覧表示。PGM / PNG / JPEG / TIFF 等のプレビュー。
- 名前・パス・トピック検索。日付、画素数、フォルダー容量で並べ替え。
- 関連画像切り替え、原寸画像を中央に表示するビューアー。
- 画像寸法、画素数、地図解像度、関連ファイルの一覧。
- rosbag2 の `metadata.yaml` からトピック名・型・メッセージ件数・収録時間を表示。
- データの合計容量と、保存先ドライブの空き容量。
- 人工サンプルで、フォルダーの一時保管・復元を試せます。

## データ保護

**自動検出と `--root` で指定したソースは読み取り専用です。** 元データの削除・移動・変更は行いません。画像変換はメモリー上で行います。日付による自動削除や保留ルールはありません。

手動で整理操作を有効にする場合だけ、専用のローカルテストフォルダーを指定します：

```sh
bash start.sh --manage-root "/path/to/local-test-data"
```

外付けドライブの標準マウント領域は管理モードで指定できません。一時保管はデータを同じソース内の `.catalog-trash` に移動します。復元先に同名フォルダーがある場合は上書きしません。シンボリックリンクを含むフォルダーは移動しません。**一時保管では容量は解放されません。完全削除機能はありません。**

## 実行環境とサンプルの保存場所

リポジトリーや SSD にライブラリ・サンプルを書き込まないように、以下のコンピューター側の場所を使用します。

| | 実行環境 | 人工サンプル |
|---|---|---|
| macOS | `~/Library/Caches/robot-data-manager` | `~/Library/Application Support/robot-data-manager` |
| Linux | `${XDG_CACHE_HOME:-~/.cache}/robot-data-manager` | `${XDG_DATA_HOME:-~/.local/share}/robot-data-manager` |

Git に含めるのはプログラム・説明・テストだけです。実際の地図、rosbag、仮想環境、キャッシュは含めません。

## 制限

- rosbag の本体再生・バイナリー解析・破損検査には対応していません。メタデータがない記録は話題の詳細を表示できません。
- 日付は rosbag メタデータの時刻（JST）を優先。それ以外はフォルダー名を参考にします。
- 複数画像がある地図の画素数は代表画像の値です。容量は関連ファイルの論理サイズの合計です。
- MOLA 等の三次元データは既存スクリーンショットを表示し、三次元点群自体は描画しません。
- PC のシンボリックリンクの整理は別途必要です。
- 読み取り権限がないフォルダーは探索できません。非常に大量のファイルがある場合、再スキャンには時間がかかります。
- ローカル専用です。サーバーは 127.0.0.1 のみで待ち受けます。

## 開発・テスト

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest -v
.venv/bin/python app.py --no-auto
```

自動検出、接続変更、読み取り専用拒否、画像変換、メタデータ、リンク拒否、一時保管・復元、復元先衝突を一時フォルダーで検証します。
