地図・rosbag が保存された SSD を接続してから、以下を実行してください
# MACとLINUXの実行方法

```sh
git clone https://github.com/fsy1766455796/robot-data-manager.git
cd robot-data-manager
bash start.sh
```

http://127.0.0.1:8765 を開いてください。

# Windowsの実行方法
```sh
git clone https://github.com/fsy1766455796/robot-data-manager.git
cd robot-data-manager
py bootstrap.py --root "E:/"
```

SSD を接続して、以下を実行してください。E:/ は実際の SSD のドライブ文字に置き換えてください。
